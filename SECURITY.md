# Security Policy

## Supported versions

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Use GitHub's private vulnerability reporting:
<https://github.com/arielsrv/dotnet-executor-service/security/advisories/new>

You will receive an acknowledgement within 72 hours. Once the issue is confirmed,
a fix will be released as soon as practical and credited to you unless you prefer otherwise.
